# 更新记录

## 0.7.0-rc3

- 新增直角阶梯外形的三视图联合重建，核对长宽高、原生B-Rep投影和内部可见直线。
- 新增孔引线及孔深标注识别，支持俯视图中的Z向平底盲孔、通孔、通底与盲底圆柱沉孔。
- 缺深度、底形或视图对应时先询问；新增沉孔两级深度、局部材料厚度和底壁检查。
- 不能由已识别孔特征解释的隐藏线会停止建模，防止把未知内部腔体填成实心。
- 修复DWG原生导出打散LEADER引线及箭头填充图形干扰轮廓的问题。
- 图纸生成的原生文件与STEP采用任务唯一名称，避免SolidWorks2024同名文件打开冲突。
- 保存重开后复核真实特征深度、终止方式、圆柱面区间、盲孔平底、体积及草图完全定义。
- 界面提供可下载的带尺寸、孔位表及隐藏线的三视图示例；精确流程继续消耗0模型API Token。

## 0.6.0-rc1

- 添加DXF/DWG/PDF二维图纸上传，保留本机原文件及哈希。
- 精确矢量流程支持直线、圆弧、圆和多段线的等厚拉伸、圆孔及贯穿槽，无需模型密钥或Token。
- 多视图先编号并询问，缺少厚度、贯穿意图、单位或标注冲突时停止澄清。
- DWG通过SolidWorks原生导入，仅导出Model图纸并恢复系统导出选项，避免默认图框混入。
- 生成真实尺寸驱动草图，核验完全定义、零Fix、保存重开几何、STEP实体数和四视图，交付带校验和的ZIP。
- PDF的1至4页在本机渲染成参考图片，继续使用原有视觉模型流程；不作为精确矢量输入。
- 保留可选的Magpie/ModelScope免费路由；实际免费模型和装配体调用仍待用户配置可用令牌与额度后验证。

## 0.4.0-rc13

- 三视图统一使用实测固定底座坐标系，通过原生相机回读检查朝向。
- 预览标注等轴测、前视图、俯视图、右视图，仅显示当前清单中的四张图。
- 规划模型复核发现预览问题后，执行模型仅重出预览，再由规划模型复核，最多修正一次。
- 修正次数按任务记录，预览和交付包按版本递增。复核已修正模型时保留旧版本。
- 无效原交付包在创建新任务前拒绝，避免遗留虚假的排队任务。
- 失败、中断的修正不自动重放；几何或配合问题不会用重出图片绕过。

Windows x64 预发布版，原生 CAD 已验证环境为 SolidWorks 2024。
另一台电脑的真实 CAD 建模兼容性仍待验证。
