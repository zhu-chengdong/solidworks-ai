# 更新记录

## 0.4.0-rc13

- 三视图统一使用实测固定底座坐标系，通过原生相机回读检查朝向。
- 预览标注等轴测、前视图、俯视图、右视图，仅显示当前清单中的四张图。
- 规划模型复核发现预览问题后，执行模型仅重出预览，再由规划模型复核，最多修正一次。
- 修正次数按任务记录，预览和交付包按版本递增。复核已修正模型时保留旧版本。
- 无效原交付包在创建新任务前拒绝，避免遗留虚假的排队任务。
- 失败、中断的修正不自动重放；几何或配合问题不会用重出图片绕过。

Windows x64 预发布版，原生 CAD 已验证环境为 SolidWorks 2024。
另一台电脑的真实 CAD 建模兼容性仍待验证。
